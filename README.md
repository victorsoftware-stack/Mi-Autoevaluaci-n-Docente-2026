# Autoevaluación Docente 2026 - Colegio Santo Domingo Bilingüe (CSDB)

Herramienta interactiva web para el proceso de autoevaluación docente 2026 del Colegio Santo Domingo Bilingüe (Bogotá).

## Características

- Flujo de 8 pasos guiados para docentes.
- Generación de reportes y exportación en formato PDF con jsPDF.
- Interfaz moderna, accesible y optimizada para dispositivos móviles y de escritorio.
- Sin dependencias de compilación; funciona como aplicación web estática (Vanilla HTML/CSS/JavaScript).

## Uso local

Para ejecutar el proyecto localmente:

1. Clona el repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd Autoevaluacion-Docente-2026
   ```

2. Inicia un servidor web local:
   ```bash
   # Con Python
   python -m http.server 8080

   # O con Node.js / npx
   npx serve .
   ```

3. Abre en tu navegador:
   ```
   http://localhost:8080
   ```
